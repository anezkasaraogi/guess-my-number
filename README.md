# My Python Games Collection 🐍

A collection of mini-games built while learning Python.

## Games Included:

### 1. Guess My Number 🎲
A game where you try to guess a hidden number between 1 and 99.
* **File:** `guess_game.py`
  
**Concepts Practiced:**
* **Randomization:** Using the `random` library to generate secret numbers.
* **User Input Handling:** Capturing and converting string input to integers.
* **Conditional Logic:** Using `if/elif/else` to provide feedback (Higher/Lower).
* **While Loops:** Keeping the game running until the correct guess is made.

### 2. The Ancient Game of Nimm 💎
A strategy game where players take turns removing 1 or 2 stones from a pile.
* **File:** `game_of_nim.py`

**Concepts Practiced:**
* **Input Validation:** Using `while` loops to let users to only pick 1 or 2 stones.
* **Boolean Logic:** Using `and` / `or` operators for complex conditions.
* **Turn-based Logic:** Implementing a "toggle" to switch between Player 1 and Player 2.
